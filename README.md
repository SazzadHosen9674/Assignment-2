# MovieExplorer

A React app to browse and search TV shows, with a details modal for more info.

## Tech Stack
React, React Router, Tailwind CSS, [TVMaze API](https://www.tvmaze.com/api)

## Getting Started
```bash
git clone <your-repo-link>
cd <your-project-folder>
npm install
npm run dev
```
